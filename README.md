# Projeto: Criando cadastro de produtos e dashboard para deploy

## Objetivo

Criar um sistema de cadastro de produtos e fazer um dashboard com os dados já registrados e os novos.

## Pré-requisitos

```
python 3
poetry
pyenv
```

## Como iniciar este projeto

- No terminal, clonar o repositório usando:

```
git clone git@github.com:c-Tos1wa/dashboard_deploy.git
```

- Dentro da pasta criada:

```
poetry install
```

- Ativando o ambiente virtual:

```
eval $(poetry env activate)
poetry run jupyter-lab
```
